 Scenario Description
This console application tracks student academic performance by calculating total points earned, computing completed study weeks, and evaluating honors eligibility using core Dart variables, arithmetic operators, and comparison operators.


Required Data Types & Operators Used
`String`: `studentName` (Student's name)
`int`**: `completedModules` (Number of completed modules)
`double`: `moduleScoreAverage` (Average score per module)
`bool`: `hasSubmittedAllTasks` (Submission status)
Arithmetic Operators: `*` (multiplication), `~/` (integer division), `%` (modulo)
Comparison Operators: `>=` (greater than or equal to), `==` (equal to)
