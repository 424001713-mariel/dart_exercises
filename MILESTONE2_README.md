I designed this Coursera-inspired Dart program around a clean object-oriented hierarchy to mirror how real educational platforms organize different learning materials without duplicating code. By creating a CourseraCourse base class with private fields (_isCompleted) and getters, I ensured that course completion data remains protected while allowing specialized subclasses like VideoLesson and QuizAssessment to inherit core attributes. I used method overriding (@override) on showInfo() so each learning format displays its own relevant metrics, while implementing the Completable abstract class to guarantee consistent completion behavior across all items. To share offline download functionality with both video lessons and standalone StudyGuide objects without forcing rigid inheritance, I introduced the Downloadable mixin. Finally, I integrated Future and async/await in syncProgressToCloud() to simulate real-world server latency, ensuring the application stays responsive while saving user progress. Overall, combining encapsulation, polymorphism, mixins, and asynchronous logic prepares this backend structure directly for building reactive Flutter widgets in the next phase of the course.
